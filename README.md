# Français

## À propos

Passionné par l'administration systèmes et réseaux, je conçois et exploite des infrastructures Linux en autonomie : serveurs Debian, conteneurs Docker, supervision et automatisation. Mon terrain d'expérimentation : une infrastructure de serveurs Minecraft évolutive. Mon parcours comprend aussi l'administration Windows Server, la gestion des accès et le support informatique.

## Ce que je fais

- **Administration** : Linux, Debian, Windows Server, Active Directory, groupes et GPO.
- **Conteneurs et virtualisation** : Docker, Docker Compose, Kubernetes (K8s), Proxmox, Hyper-V, VMware, VirtualBox.
- **Réseau et sécurité** : TCP/IP, VLAN, DHCP, DNS, reverse proxy Nginx, pare-feu, durcissement SSH.
- **Supervision et support** : Grafana, journaux, sauvegardes Acronis/Synology, diagnostic et résolution d'incidents.
- **Diagnostic matériel** : OCCT (tests de stabilité), CrystalDisk (santé des disques), recherche de pannes.
- **Développement** : plugins Java, bots Discord, scripts Python et shell.
- **DevOps** : Git, GitLab, pipelines CI/CD ; GitHub Actions en cours d'apprentissage.
